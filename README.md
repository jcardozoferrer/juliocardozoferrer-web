# juliocardozoferrer.com

Sitio personal de Julio Cardozo Ferrer (Founder & Director, STM LATAM).

- `index.html`: la página completa (HTML, CSS y JS en un solo archivo).

- Publicado en Netlify: cada cambio que se sube a la rama `main` se publica solo.
